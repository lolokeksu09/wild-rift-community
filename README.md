# Сообщество Wild Rift

Адаптивный русскоязычный сайт для игроков Wild Rift: клубы, публикации и комментарии, поиск компании и игроков, общие и личные чаты, профили и игровые события. Отдельный проект, не RiftCore; публичное название пока не выбрано.

Текущая согласованная база оформления — **этап 24**, включает этапы 1–24. Тёмная сливовая палитра, светлая типографика, розовые акценты; на телефоне пять нижних разделов и масштаб 90%. Пользовательские аватары и обложки сохраняются. Следующие изменения дизайна начинаются с этапа 25.

[Паспорт этапа 24](docs/DESIGN_BASELINE_STAGE24.md) · [План и история дизайна](docs/WEB_REDESIGN_PLAN.md) · [Карта документации](docs/README.md)

Репозиторий: [lolokeksu09/wild-rift-community](https://github.com/lolokeksu09/wild-rift-community), публичный, основная ветка `main`.
Сайт: https://139.100.205.135. Последняя подтверждённая установка, текущий выпуск кода и способ обновления — в [PROJECT_STATE.md](PROJECT_STATE.md). [Подтверждение](docs/DESIGN_BASELINE_STAGE24.md) · [Диагностика VDS](docs/VDS_READONLY.md).

## Стек и структура

Node.js **>=24.19.0 <25**, встроенный SQLite (версия схемы **28**), Sharp, Docker и Caddy. Клиент — HTML, CSS и JavaScript; права проверяет сервер.

| Каталог | Назначение |
| --- | --- |
| server/ | HTTP API, бизнес-правила, SQLite и серверные модули |
| server/public/ | Браузерный интерфейс и ресурсы сайта |
| server/tests/ | Серверные тесты доступа, хранения и миграций |
| tests/ | DOM и браузерные сценарии |
| deploy/ | Docker/Caddy, установка и резервные копии |
| docs/ | Требования, эксплуатация и история веб-функций |
| .github/workflows/ | Проверки и ручные операции VDS |

## Локальный запуск

```bash
npm ci
npm start
```

Адрес выводится в терминале; по умолчанию http://127.0.0.1:3000. Локальный запуск не публикует сайт на VDS. Переменные окружения и API — [SERVER.md](docs/SERVER.md).

## Проверки

```bash
npm ci --prefix tests
npm run verify
npm run test:events-ui --prefix tests
npm run test:account-ui --prefix tests
```

Браузерные проверки требуют установленного Chromium для Playwright:

```bash
npx --prefix tests playwright install chromium
npm run test:browser --prefix tests
```

DOM-проверки не подтверждают внешний вид и работу клавиатуры на настоящем телефоне. [QA](docs/QA.md) · [Серверные проверки](docs/SERVER_QA.md).

## Эксплуатация и разработка

Развёртывание выполняется отдельно по команде владельца. `.github/workflows/vds-deploy.yml` не менять ради очистки репозитория. При обновлении сохраняются пользовательская база, медиа, аккаунты и права.

[Развёртывание](docs/DEPLOYMENT.md) · [Копии](docs/BACKUP.md) · [Внешнее резервирование](docs/OFFSITE_BACKUP.md) · [История изменений](docs/CHANGELOG.md).

Перед работой прочитать [AGENTS.md](AGENTS.md), [состояние проекта](PROJECT_STATE.md) и [рабочий процесс](docs/WORKFLOW.md); остальные документы — по затронутой области. Сохранять утверждённое оформление; проверять доступ, потерю соединения, повторы запросов и сохранение черновиков. Приватный контент нельзя защищать только скрытием элементов интерфейса.

Сервис находится на раннем этапе; готовность к массовому запуску не подтверждена. Автономный [prototype.html](docs/prototype.html) сохранён для исторического DOM-теста; текущий сайт находится в server/public/.

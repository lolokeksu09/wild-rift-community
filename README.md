# Сообщество Wild Rift

Основной продукт — нативное Android-приложение с общими аккаунтами и данными существующего сервера. Техническая основа клиента: **Kotlin + Jetpack Compose + Material 3**. Русский интерфейс, тёмная тема с золотыми акцентами, клубы, обсуждения, переписка и поиск компании.

**Статус на 05.10.2026:** серверный код 0.31; подготовлены архитектура и план Android. Созданы Gradle-проект и гостевой debug APK A01; установка проверяется отдельно. Публичное название не выбрано. Это отдельный проект, не RiftCore.

## Структура

| Каталог | Назначение |
|---|---|
| android/ | Инструкции будущего клиента; исходники появятся на A01 |
| server/ | Node.js API, SQLite, серверные правила и web-клиент в public/ |
| server/tests/ | Проверки серверного поведения и доступа |
| tests/ | DOM и браузерные проверки существующего интерфейса |
| deploy/ | Эксплуатация и восстановление |
| docs/android/ | Актуальная архитектура, дизайн, API, статус и этапы Android |
| docs/history/ | Сохранённые ранние описания; не инструкции текущего запуска |
| .github/workflows/ | Проверки и отдельный управляемый выпуск сервера |

Сервер хранит данные и проверяет права. Приложение обращается к HTTPS API; прямой доступ телефона к SQLite не нужен. Web-клиент остаётся работающим эталоном дизайна, но Android не зависит от открытого сайта.

## Проверки и запуск

Для сервера нужен Node.js >=24.19.0 <25. Зависимости устанавливаются через npm ci. Команды:

```text
npm run check:docs
npm run verify
npm start
```

Переменные и локальный запуск — [SERVER.md](docs/SERVER.md). Подготовка окружения Android и критерии настоящей сборки — [android/README.md](android/README.md). Эти команды пока не собирают APK.

## Работа над обновлением

Прочитать [AGENTS.md](AGENTS.md), выбрать один этап и заполнить [шаблон задачи](docs/templates/ANDROID_TASK.md). Зафиксировать контракт, состояния экрана и критерии; реализовать сценарий; проверить сборку и права; записать результаты в статусе. Успешная web-проверка не подтверждает работу Android.

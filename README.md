## Структура

| Каталог | Назначение |
|---|---|
| server/ | Node.js API, SQLite, серверные правила и web-клиент в public/ |
| server/tests/ | Проверки серверного поведения и доступа |
| tests/ | DOM и браузерные проверки существующего интерфейса |
| deploy/ | Эксплуатация и восстановление |
| docs/history/ | Сохранённые ранние описания; не инструкции текущего запуска |
| .github/workflows/ | Проверки и отдельный управляемый выпуск сервера |


## Проверки и запуск

Для сервера нужен Node.js >=24.19.0 <25. Зависимости устанавливаются через npm ci. Команды:

```text
npm run check:docs
npm run verify
npm start
```

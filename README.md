# Сообщество Wild Rift

Адаптивный русскоязычный сайт для игроков Wild Rift: клубы, публикации и комментарии, поиск компании и игроков, общие и личные чаты, профили и игровые события. Отдельный проект, не RiftCore; публичное название пока не выбрано.

Текущая согласованная база оформления — **этап 24**, включает этапы 1–24. Тёмная сливовая палитра, светлая типографика, розовые акценты; на телефоне пять нижних разделов и масштаб 90%. Пользовательские аватары и обложки сохраняются. Следующие изменения дизайна начинаются с этапа 25.

[Паспорт этапа 24](docs/DESIGN_BASELINE_STAGE24.md) · [План и история дизайна](docs/WEB_REDESIGN_PLAN.md) · [Карта документации](docs/README.md)

# Сообщество игроков Wild Rift

Статус: проектирование, версия документации 0.1 от 28 сентября 2026 года.
Название продукта пока не выбрано. Репозиторий: `lolokeksu09/wild-rift-community`, приватный, основная ветка `main`. Это отдельный проект, не RiftCore.

Социальная платформа по духу Amino: профили, публикации, клубы, чаты и поиск компании для Wild Rift. Главный сценарий: найти свой клуб, познакомиться и сыграть вместе.

## С чего начать

1. Прочитать [ТЗ](docs/SPEC.md) и [план](docs/ROADMAP.md).
2. Открыть `docs/prototype.html` в браузере: это кликабельный эскиз, а не работающее приложение.
3. Зафиксировать решения из [DECISIONS.md](docs/DECISIONS.md).
4. Выбрать следующую задачу в [GitHub Issues](https://github.com/lolokeksu09/wild-rift-community/issues).
5. Реализовать один сквозной сценарий по плану, затем провести закрытый пилот.

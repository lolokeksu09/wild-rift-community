# Решения и вопросы

## Подтверждено пользователем

- Отдельный проект по Wild Rift, не продолжение RiftCore.
- Большое сообщество с общением между людьми, по духу Amino.
- Нужны ТЗ, оформление GitHub и понятный порядок старта.

## Предложено в этом пакете

- Первый клиент: адаптивный web с возможностью установки.
- Первый язык интерфейса: русский.
- Репозиторий на старте приватный.
- Документация и интерфейс не используют невыбранное брендовое название.
- Первый релиз без голосового сервера, видеохостинга и интеграции с игровыми данными.
- Хронологическая лента раньше рекомендательного алгоритма.

Эти решения можно пересмотреть до реализации соответствующего модуля.

## Открыто до разработки серверной части

1. Бюджет на инфраструктуру и доступные средства разработки.
2. Хостинг и стек; нельзя автоматически переносить конфигурацию Amvera из RiftCore.
3. Механизм входа и восстановления.
4. Источник каталога чемпионов и разрешённых изображений.

## До публичного запуска

Возрастные правила, юрисдикция и документы обработки данных; сроки хранения и удаления; лицензия кода; состав модерации и поддержка; квоты медиа; сценарий инцидентов. Эти вопросы не блокируют локальный эскиз, но блокируют обещания реальным пользователям.

## Как фиксировать решение

Для каждого существенного выбора записать дату, контекст, альтернативы, принятое решение, последствия и способ пересмотра. Не выдавать рекомендацию за согласованное решение.

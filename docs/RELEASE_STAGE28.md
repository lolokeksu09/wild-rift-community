# Этап 28 — отмена турнира до старта

Организатор указывает причину и подтверждает окончательную отмену. История команд сохраняется, приглашения закрываются, отменённый турнир не занимает лимит. Запущенные и завершённые турниры отменять нельзя. Дизайн сохранён.

Схема SQLite 25 сохраняет аккаунты, составы и сыгранные результаты. Установщик проверяет холодную копию и резервирует данные до переключения. Не запускать старое приложение на новой базе.

Перед упаковкой прошли npm run verify (125 серверных тестов и DOM-сценарии), два теста инструментов выпуска и проверка синтаксиса установщика. GitHub Actions и визуальная проверка нового действия на реальном телефоне на момент выдачи ZIP отдельно не подтверждены. Установка на VDS выполняется владельцем через Termux.

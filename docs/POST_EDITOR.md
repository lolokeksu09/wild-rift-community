# Редактор публикаций · 0.20

Один серверный черновик на пару клуб/автор, до 100 на аккаунт. Черновик приватен: другие участники, владелец клуба и модераторы его не читают. Список «Мои черновики» в профиле показывает актуально доступные клубы. Схема 14→15 сохраняет прежние данные.

## Сохранение и восстановление

GET `/api/clubs/:id/draft` возвращает только черновик текущего аккаунта при действующем member. PUT `{title,body,imageId,version}` принимает неполный текст (0–100/0–4000), создаёт с ожидаемой версией 0 либо обновляет текущую. Версия увеличивается при изменении; идентичный повтор с текущей/предыдущей версией возвращает прежнюю запись без нового обновления. Несовпадение версии — 409, чужой текст не перезаписывается. GET `/api/drafts` возвращает собственные название/клуб/время, без чужого userId в параметрах.

UI загружает сохранённое при открытии редактора, сохраняет после 900 мс паузы и по кнопке. При навигации отправляет текущую попытку сохранения. Несохранённые текст/File и непринятая попытка публикации остаются только в памяти текущей вкладки; localStorage/IndexedDB не используются. При закрытии вкладки с несохранённым/неподтверждённым состоянием браузер предупреждает. При потере связи нужно дождаться подтверждения сохранения: закрытие вкладки всё ещё может потерять локальную правку. В новом сеансе/на другом устройстве восстанавливается только подтверждённая серверная версия.

При конфликте текст остаётся в форме, автосохранение остановлено; пользователь явно подтверждает загрузку серверной версии с потерей локальной правки. При смене аккаунта память сбрасывается, отложенные операции проверяют автора перед отправкой. 401/403/404 закрывают редактор и очищают показанный текст/изображение. Пустой черновик допустим, для публикации заголовок/текст обязательны.

## Изображение и предпросмотр

Одно JPEG/PNG/WebP через существующий серверный декодер/квоты и удаление метаданных. Выбранный файл виден локально, сохранённое вложение — через защищённый GET /api/media/:id. Доступ к draft-image требует автора и текущего членства; другие участники его не получают. Нельзя присвоить файл черновика аватару, обложке или другому посту/черновику. При снятии/замене вложения и удалении черновика SQL-trigger удаляет файл только если он больше нигде не используется.

Предпросмотр — экранированные заголовок и текст с переносами и изображением; HTML/скрипты не исполняются. Показываются название клуба, счётчики 100/4000 и явная отметка, что публикация не отправлена. Удаление черновика требует подтверждения и версии.

## Публикация

POST `/api/clubs/:id/draft/publish` `{version,clientId}` читает только сохранённый текст. Проверяет member, версию, непустой текст и авторство изображения. В одной транзакции: вставка обычного поста, упоминания, удаление черновика. Вложение сохраняется, поскольку уже связано с постом. Результат и права просмотра обычного опубликованного поста неизменны. Сохранение черновика не отправляет упоминания/уведомления.

Повтор с тем же clientId при уже опубликованном посте и отсутствии нового черновика возвращает прежний id без дубля. Если новый черновик уже существует, старый повтор — 409, новый текст сохраняется. UI после неясного сетевого/5xx-ответа блокирует изменения и предлагает «Проверить публикацию» с тем же clientId; автоматически не публикует. Старый обычный POST posts поддерживается для прежних клиентов. Наличие draft-image запрещает присвоение им через старый endpoint.

Выход/исключение удаляет строку членства → черновик и неиспользуемый файл каскадно очищаются. Бан немедленно скрывает черновик/файл и запрещает публикацию; снятие бана удаляет членство и также очищает старый черновик. Уже опубликованные посты/вложения остаются обычным контентом клуба.

## Проверки

`server/tests/drafts.test.mjs`: миграция и холодная копия, собственный доступ, запрет владельцу клуба/другим/аватару, параллельные версии, перезапуск, атомарная публикация/повтор/защита нового черновика, удаление медиа, выход/бан. `tests/composer-ui.dom.cjs`: сохранение/предпросмотр, конфликт, lost publish response без дубля. `tests/browser-drafts.mjs`: 360/1440 px, авто-сохранение файла, безопасный preview, новый сеанс, конфликт/явная загрузка, потерянный ответ и повтор, очистка при выходе. Docker smoke проверяет фактическую 14→15 под node. Внешних сообщений, новых зависимостей, Markdown, offline-sync и редактирования опубликованного поста этот выпуск не добавляет.

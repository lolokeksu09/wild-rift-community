# Сервер 0.3: проверка от 29.09.2026

Среда: Node 24.19.0, локальный HTTP на случайном loopback-порту, отдельная временная SQLite для каждого сценария. Реальные данные пользователей не использовались.

## Результаты

`npm test`: 14 passed, 0 failed (включая родительский тест набора).

Проверены независимые аккаунты и сеансы; безопасный ответ регистрации; ограничения логина/пароля; дубли логинов; неправильный JSON; Origin/CSRF/Host; запись без входа; заявки и права владельца; запрет чтения по прямым ID; авторство из сеанса, а не тела запроса; свой профиль; хеширование пароля и токена; пагинация при появлении нового поста; сохранение после перезапуска; отзыв доступа при блокировке; невозможность обойти бан выходом/вступлением; открытое чтение гостем; отсутствие дубля членства; удаление автором; выход везде; запрет выдачи БД/исходников; размер тела запроса; лимиты входа и истечение сеанса.

`npm run test:server-ui --prefix tests`: PASS. Формы клиента выполняли запросы к настоящему локальному серверу и SQLite: регистрация → клуб → пост → комментарий → профиль → выход/вход → подтверждение удаления. HTML во введённом тексте не создаёт элементы на странице.

`npm test --prefix tests`: предыдущие DOM-тесты автономного прототипа также прошли.

Проверены синтаксис JavaScript и относительные ссылки документации.

## Ограничения проверки

jsdom не выполняет layout и не заменяет настоящий браузер. Cookie/Origin в UI-тесте передаются тестовым адаптером; реальные cookie-флаги отдельно проверены HTTP-тестами. Работа с экранной клавиатурой, визуальная адаптивность и browser-native dialog не подтверждены. Нагрузочные испытания, аудит production-инфраструктуры, доставка email и внешние игровые интеграции не проводились.

## Воспроизведение

```bash
npm test
npm ci --prefix tests
npm test --prefix tests
npm run test:server-ui --prefix tests
```

Для ручной проверки: npm start; открыть два независимых браузерных сеанса по адресу из вывода; создать владельца и участника. Не использовать основной пароль пользователя или Riot.

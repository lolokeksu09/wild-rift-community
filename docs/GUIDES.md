# Руководства игроков · 0.23

Принятый участник создаёт руководство во вкладке постов клуба. Заголовок до 100 символов, текст до 12 000, краткое описание до 240, чемпион до 40. Темы: чемпион, сборки/руны, макро, роли, для новичков. Версия игры обязательна: например 7.3 или 7.3a; она указана автором, приложение не подтверждает её актуальность и не использует Riot API.

Каталог открывается с главной кнопкой «Руководства». Поиск по заголовку, тексту и описанию, фильтры темы, чемпиона, точной версии и клуба. Поиск учитывает Unicode без регистра, чемпион ищется по части имени. Порядок по ID публикации, 20 результатов и курсор. В карточке четыре строки текста; чтение раскрывает полный текст. Комментарии, реакции и сохранения обычные.

Предпросмотр безопасно показывает текст без выполнения HTML. Автор редактирует текст и метки вместе. Устаревшая версия даёт конфликт и сохраняет локальный ввод; можно загрузить свежую публикацию. Повтор после потери ответа использует прежний clientId и payload. Выход из клуба/бан закрывает запись; отказ доступа очищает форму. Несохранённый ввод остаётся только в текущей вкладке, при уходе появляется предупреждение. Серверного черновика и изображения у формы руководства пока нет.

## API

- GET /api/guides: q, topic, champion, gameVersion, club, before; возвращает viewerId, posts, next.
- POST /api/clubs/:id/guides: title, body, topic, champion, gameVersion, summary, clientId.
- PATCH /api/posts/:id/guide: те же поля плюс version. Только автор при текущем членстве. Обычный PATCH поста для руководства запрещён.

JSON до 65 536 байт только для создания/редактирования руководства, чтобы длинный русский текст помещался. Права клуба, бан и двусторонние блокировки проверяются до выдачи/пагинации. Закрытый клуб не раскрывается гостю. Удаление поста каскадно удаляет метаданные.

## Миграция и приёмка

Схема 17→18 добавляет guides и индексы, сохраняет посты, голоса, черновики и версии правок. Перед обновлением установщик останавливает приложение, делает холодную копию и проверяет миграцию отдельно. Откат требует прежнего кода и восстановления копии; не понижать user_version вручную.

server/tests/guides.test.mjs проверяет фактическую схему 17, сохранность и восстановление, доступ, Unicode, длинный текст, фильтры/пагинацию, атомарные повторы и конфликты. tests/browser-guides.mjs проверяет 360/1440 px: безопасный предпросмотр, потерянный ответ создания, каталог, полное чтение, конфликт редактирования и отзыв доступа. CI также проверяет общие сценарии управления постами и опросов. Результаты фиксируются в PR/Actions.

# Прототип v0.2: отчёт проверки

Дата: 28.09.2026. Связана задача #2. Это проверка автономного демонстрационного интерфейса, не приёмка приложения.

## Выполнено

- Node --check: синтаксис JavaScript корректен.
- DOM-тесты в jsdom 30.1.1: публикация; экранирование HTML пользователя; включение/выключение реакции; сохранённое; комментарии; вступление в клуб → чат; создание группы; заявка и отмена; редактирование профиля; восстановление состояния после повторной загрузки; поиск; исчезновение комнаты после выхода; подтверждение сброса; повреждённое локальное хранилище.
- Ошибок выполнения в этих сценариях не зафиксировано.
- В HTML нет внешних runtime-ресурсов: шрифтов, скриптов и изображений.

## Не выполнено

Playwright найден, но Chromium отсутствует. Установка завершилась ошибкой загрузки архива. Поэтому визуальный рендер, отсутствие переполнения на 360/390/768/1440 px, экранная клавиатура и поведение native dialog в реальном браузере пока НЕ подтверждены. jsdom использует адаптер dialog и не моделирует layout или фактическую доступность.

## Проверка владельцем

Открыть docs/prototype.html на телефоне. Пройти вкладки; создать пост; вступить в открытый клуб и написать сообщение; создать группу; изменить профиль; перезагрузить. Проверить читаемость, отсутствие горизонтального скролла, доступность кнопок при открытой клавиатуре. Не вводить секретные данные. Прислать замечания и скриншоты неудобных экранов.

## Ограничения

Все исходные участники и публикации вымышлены. Хранение только на устройстве, без серверной синхронизации. Режим file:// может ограничивать сохранение в зависимости от браузера. Приложение не отправляет сообщения реальным людям. Серверную авторизацию и приватность этот прототип не обеспечивает.

# Этап 30 — уведомления о турнирных приглашениях

Приглашения появляются в существующем центре уведомлений. Счётчик учитывает непрочитанные ответы и ожидающие приглашения; карточка ведёт к точному турниру. Открытие страницы не заменяет согласие игрока. После ответа и закрытия приглашения оно не входит в счётчик. Блокировки и ограничения капитана/организатора учитываются на сервере.

Доступны старые приглашения с пагинацией, независимо от публичного списка последних 50 турниров. Список обновляется при открытии центра; счётчик использует существующий опрос. Схема SQLite остаётся 25, новая миграция не требуется. Установка этапа 29 подтверждена владельцем.

npm run verify: 129 серверных тестов и DOM-проверки, включая центр приглашений с реальным HTTP, точный переход, принятие и обновление счётчика. CI и визуальная проверка на настоящем телефоне отдельно не подтверждены на момент упаковки. Установка нового выпуска выполняется через Termux отдельно.

# Знакомство, выбор клуба и чтение · 0.27

Главная дополнена тремя открытыми клубами из доступного каталога: обложки, темы, описания и честные счётчики, включая ботов. Это подборка по существующему порядку каталога, без заявления о популярности или персональном подборе. На телефоне карточки листаются горизонтально внутри своего блока.

Каталог клубов объединяет поиск по названию/описанию/меткам, выбор темы, открытые/свои клубы и сортировку по новизне, последнему доступному обсуждению или названию. Фильтры пересекаются, показывают число совпадений и сбрасываются одной кнопкой. Работа идёт по текущим максимум 100 карточкам `/api/clubs`; полного серверного поиска всех клубов пока нет. Порядок новых клубов берётся из API, свежесть обсуждений — из разрешённого сервером `lastPost`. Фильтры живут в памяти вкладки и сбрасываются при смене аккаунта.

В лентах длинные тексты сокращаются до 360 Unicode-символов. Ссылка открывает полный текст на странице публикации; текст остаётся экранированным. Оценка времени чтения приблизительна (180 слов в минуту). При переходе на другую страницу открывается её начало и фокус переходит к содержимому; переход к конкретному комментарию сохраняет прокрутку к ответу.

У клубов, публикаций и опубликованных профилей есть копирование прямой ссылки. Используется только clipboard API, ничего не отправляется другим людям. Если браузер запрещает копирование, открывается диалог с доступным для выделения адресом. Ссылка не меняет права на закрытое содержимое.

Поиск обсуждений доступен из шапки. После входа кнопка «Написать» открывает редактор текущего клуба с членством либо первого своего клуба; без членства ведёт к выбору клуба. Подсказки на личной главной предлагают описание/роли и вступление в клуб. Публичность профиля не обязательна. Когда оба действия выполнены, подсказки скрываются по фактическим данным аккаунта.

Карточки, чтение, шапка телефона, загрузка и состояния фильтров доработаны в прежней графитово-золотой палитре. Анимация загрузки/карточек отключается при reduced-motion. Внешних шрифтов, изображений, сервисов и зависимостей нет. SQLite остаётся схемы 19. Наполнение ботами повторно не запускается: флаг SEED_DEMO_COMMUNITY снят с workflow 0.27.

`tests/browser-refinement.mjs`: 360/390/768/1440 px, пересечение/сброс/сортировка фильтров, копирование и отказ clipboard, состояние первых шагов по фактическим данным, быстрый редактор, сохранение черновика при поиске, сокращение/полный текст и экранирование, отсутствие горизонтального переполнения. Существующие браузерные проверки запускаются в CI. DOM-среда имитирует scrollTo, настоящая прокрутка проверяется в Chromium.

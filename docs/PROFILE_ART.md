# Иллюстрация стандартной обложки профиля

Этап 19, 8 октября 2026. [Файл для сайта](../server/public/profile-cover.webp), 1600 × 534, WebP. Изображение создано встроенным image_gen в режиме генерации по референсу утверждённого концепта; это иллюстрация проекта, не официальный материал Riot. Исходный результат: exec-fd0c6853-8423-4273-93e2-60cc5c32b644.png. WebP получен уменьшением и кодированием без изменения композиции.

Используется только при отсутствии coverId. Загруженные пользователем обложки не заменяются. Аватар, имя, описание, роли и другие поля берутся из аккаунта. База данных не меняется из-за этой иллюстрации.

Запрос к встроенному image_gen:

> Create a standalone wide profile cover illustration for a dark Wild Rift community website. Reference image is a UI concept: use ONLY its cover illustration as composition and mood inspiration, do NOT include any interface, typography, frame or avatar. Wide landscape 3:1. Two fantasy adventurers seen from behind resting on a rocky overlook at the left/centre, a small friendly white furry creature beside them, distant slender citadel on the right, misty mountains and valley, delicate foliage framing top left. Hand-painted sophisticated fantasy editorial illustration, detailed ink-like textures and painterly atmospheric depth, muted near-monochrome plum-gray and warm ivory palette, quiet dusk, natural poses, not glossy 3D. Keep all faces hidden. No text, no UI, no symbols, no watermark. This will be cropped as a 390px-wide profile banner; make the main silhouettes and castle readable at mobile size.

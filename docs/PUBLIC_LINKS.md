Исходный HTML содержит title, description, canonical и Open Graph для главной, каталогов, правил, существующего клуба, открытой публикации и опубликованного профиля. Пользовательский текст экранируется; описание сокращается до 180 символов после нормализации пробелов. Canonical строится только из проверенного PUBLIC_ORIGIN и пути, без параметров запроса. Картинки, Riot ID и другие игровые поля в карточку ссылки не включаются. Загрузка страниц поддерживает GET и HEAD.

Отсутствующая страница/клуб/публикация, скрытый профиль и заблокированный автор возвращают HTTP 404. Недоступная публикация клуба по заявкам и бан в клубе возвращают 403. Авторизованный участник может открыть закрытую публикацию, но её метаданные всё равно общие и noindex: заголовок и текст в карточку ссылки не попадают. Аккаунт, личные сообщения, уведомления, жалобы, сохранённое, черновики и поиск также noindex. Ответы сохраняют no-store. Это не заменяет серверные проверки API и файлов.

Внутренняя навигация и история обновляют title, canonical, description и Open Graph через `/api/page-metadata?path=...`. Метод GET повторяет серверные проверки; устаревший ответ после следующего перехода не применяется. Если сеть недоступна, остаются прежние метаданные. Этот запрос выполняется при перерисовке, а не фоновым таймером.

`/robots.txt` разрешает публичные маршруты и указывает sitemap; внутренние разделы и API исключены. Robots — указание поисковикам, не защита доступа. `/sitemap.xml` содержит публичные разделы, карточки клубов, публикации открытых клубов и opt-in профили. Закрытых публикаций, приватных разделов, текстов и файлов там нет. Список строится по текущей базе и ограничен 50 000 URL; при достижении этой границы потребуется индекс нескольких sitemap. Получение sitemap не зависит от сеанса. Изменение видимости сразу влияет на следующий ответ.

Добавлена SVG-иконка с буквой W; `/favicon.ico` перенаправляет на неё. Новых зависимостей и миграций нет, схема остаётся 20. Это исправления передачи ссылок и статусов; серверный рендер всего содержимого, социальная картинка, доступность и нагрузочные измерения не входят в пакет.

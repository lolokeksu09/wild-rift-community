# Android 0.6.0-preview

Стартовый экран получил шрифт Manrope с кириллицей: более плотные заголовки, выверенные межстрочные интервалы и читаемый текст. В шапке — компактный золотой знак и новая композиция Wild Rift Community. Такой же оригинальный знак используется в адаптивной иконке приложения, включая круглые маски и тематические иконки Android 13+. Четыре полноэкранные обложки, свайпы и существующие переходы сохранены.

Перед публикацией CI выполняет сборку, lint, JVM-тесты и четыре WelcomeUiTest на Android 15/API 35. Фактический commit и SHA256 публикуются вместе с APK. Ручная установка на телефоне, TalkBack, 200% текст и API 26 отдельно не подтверждены. Экспорт снимков использует общий Download, чтобы AGP не удалял их после тестов.

Это prerelease с временной debug-подписью. Обновление поверх предыдущей сборки не гарантируется; при переустановке потребуется повторный вход. Перед удалением сохраните доступ к аккаунту. Сервер и пользовательские данные не изменены.

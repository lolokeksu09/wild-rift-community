# Android 0.7.0-preview

Клиент совместим с серверной схемой 22: читает sanction из /api/me, показывает предупреждение или срок ограничения в профиле, очищает сеанс при 401 и сохраняет ввод при отказе 403. Ошибки ограничения и лимита 429 показываются текстом сервера. Полноэкранные обложки, свайпы, Manrope и фирменная иконка из 0.6 сохранены.

Перед публикацией CI собирает APK, выполняет lint, JVM-тесты и полный набор инструментальных тестов на Android 15/API 35: приветствие, гостевое чтение и Android Keystore. Публикуется тот же APK из проверенного job; исходный commit и SHA256 добавляются в описание.

Это prerelease с временной debug-подписью. Установка поверх предыдущего APK не гарантируется. При несовпадении подписи потребуется переустановка и повторный вход; перед удалением приложения сохраните доступ к аккаунту. Ручная проверка на телефоне, TalkBack и API 26 остаются отдельными проверками. Сервер и пользовательские данные этим выпуском не изменяются.

## Ближайшая задача A01

Создать один app-модуль Kotlin/Compose и установить debug APK с реальным сценарием: каталог открытых клубов → клуб → чтение поста. Четыре будущих раздела не означают четыре готовых экрана; сначала закончить гостевой путь.

До кода: проверить совместимую stable матрицу AGP/Gradle/Kotlin/JDK/Compose; выбрать тестовый applicationId и minSdk; закрепить фактические JSON выбранных маршрутов. Проверить доверенный HTTPS адрес без обхода сертификатов. Название продукта пока не определено.

Критерии: поиск/пагинация, loading/empty/error/offline/forbidden, возврат с сохранением позиции, современная тема/переходы, 200% текст и TalkBack. Собрать assembleDebug, lintDebug и существенные tests; установить APK, пройти сценарий и приложить доказательство.

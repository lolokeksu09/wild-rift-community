## Проверка A01 и следующая задача A02

Создан один app-модуль Kotlin/Compose; требуется подтвердить установку debug APK с реальным сценарием: каталог открытых клубов → клуб → чтение поста. Четыре будущих раздела не означают четыре готовых экрана; сначала закончить гостевой путь.

Для A01 закреплены совместимые AGP/Gradle/Kotlin/JDK/Compose, временный applicationId, minSdk и фактические JSON гостевых маршрутов. Используется доверенный HTTPS адрес без обхода сертификатов. Название продукта пока не определено.

Критерии: поиск/пагинация, loading/empty/error/offline/forbidden, возврат с сохранением позиции, современная тема/переходы, 200% текст и TalkBack. Собрать assembleDebug, lintDebug и существенные tests; установить APK, пройти сценарий и приложить доказательство.

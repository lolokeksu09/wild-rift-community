# Android 0.10.0-preview

Исправлены различия с сайтом: безопасные анонсы команд и событий для гостя, возвращение к выбранному объекту после входа, удаление из сохранённого, отдельные фильтры и формы разделов, пустой поиск до ввода запроса, открытие нужного старого комментария из уведомления и сохранение последней страницы нижних вкладок.

При ограничении аккаунта отказ отправки больше не уничтожает доступную историю, черновик и неподтверждённое сообщение. Клиент повторно проверяет право чтения; при настоящем отзыве доступа приватное содержимое скрывается. Права комментариев обновляются по свежему ответу сервера, страницы своих жалоб проверяют владельца ответа.

CI выполняет сборку, lint, JVM-проверки и инструментальные сценарии на Android 15/API 35. Дополнительные сценарии используют настоящий сервер проекта через HTTPS с отдельной временной SQLite-базой: личная переписка и блокировки, состав команды, места события, модерация и независимое обжалование. Рабочие аккаунты не участвуют. Конкретный результат CI указан по ссылке выпуска; наличие теста не считается его успешным выполнением.

Полная ручная приёмка всех форм, TalkBack, API 26 и физические устройства остаются непроверенными. Push отсутствует. Незавершённые формы вне чатов не гарантированно переживают завершение процесса; серверные черновики публикаций сохраняются отдельно.

Prerelease с временной debug-подписью. При несовпадении подписи потребуется переустановка и повторный вход. Исходный commit, SHA256 и ссылка на проверки публикуются вместе с APK. Боевой сервер, миграции и Deploy не изменяются.

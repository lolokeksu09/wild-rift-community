# Нативный клубный контент

07.10.2026. Kotlin/Compose, существующий Origin/CSRF/session-клиент; WebView не используется.

Реализованы каталог all/open/mine, поиск/метки/сортировка и непрозрачные курсоры, лента/поиск публикаций/сохранённое, структурированные руководства и фильтры, клуб/правила/вступление и отзыв заявок/выход, публикации и комментарии с ответами/упоминаниями, реакции и сохранение, опросы, серверные приватные черновики с версиями, управление настройками/обложкой/участниками/заявками/ролями/банами, приглашения и принятие кодов, передача владения, закрепления, журнал и уведомления обсуждений с отметкой чтения. Фотографии выбираются штатным Android picker и загружаются через существующий защищённый API. Жалобы/чат/профили переходят в соответствующие нативные разделы.

Права UI следуют membership/myRole/canModerate; сервер остаётся источником полномочий. Закрытый клуб без членства не запрашивает посты/закрепления. Повторы мутаций не автоматические; для создания/редактирования постов, комментариев, опросов, руководств, приглашений/передач и публикации черновика идентификатор стабилен для того же payload. Настройки и черновики используют серверную версию. Ввод сохраняется при ошибке отправки; загрузка сохранённого текста требует отдельного действия. Разрушительные действия подтверждаются.

На сервере нет отдельного API club pages и маркера чтения поста: club_page — тип жалобы на публичную страницу клуба (описание/правила); маркер чтения реализован для уведомлений обсуждений. Не добавлены вымышленные маршруты. Один черновик на клуб/аккаунт соответствует серверному контракту; это серверный черновик, не offline-очередь. Создание клуба не имеет серверного dedup, поэтому потерю ответа следует проверять в «Мои» перед ручным повтором.

Контрактные JVM-тесты проверяют безопасное чтение закрытого клуба, реальные маршруты/CSRF/запрет без повторов, поля guide/edit и курсоры/дубли комментариев. Результат сборки/тестов указывается в общем STATUS после фактического выполнения. Ручная приёмка устройства, TalkBack, offline/process death и серверные конкурентные сценарии не заявлены выполненными этим документом.

Руководства и поиск доступны также в контексте выбранного клуба через его карточку: клуб выбирается навигацией, пользователь не вводит UUID. Позиция прокрутки и активные фильтры сохраняются при переходах внутри текущего процесса. Списки сейчас используют прокручиваемую Column; виртуализация и измерение производительности на устройстве остаются полировкой, не утверждением о готовности A07.

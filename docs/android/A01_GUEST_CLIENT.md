# A01 · первый гостевой Android-клиент

Дата: 05.10.2026. Реализация готова к проверке установки. Итоговые доказательства — в STATUS.md; не считать эмуляторную проверку выполненной по одному наличию теста.

## Результат

Нативный Kotlin/Compose клиент для чтения реального сервера: каталог открытых клубов, поиск/темы/сортировка, карточка клуба/правила/публикации, полный пост/фотография/комментарии. Страницы загружаются явным действием; непрозрачный after и числовой before сохраняются. Демо-боты отмечены.

Тёмная тема и золото перенесены из сайта. Карточки, fade/slide 120–240 ms, раскрытие правил, просмотр фотографии, кнопка назад, системные отступы и клавиатура. Длительность Compose-анимаций учитывает системный масштаб. Широкие экраны используют растягиваемый список; navigation rail ещё не нужен гостевому единственному разделу.

## API и безопасность

Только GET через существующий HTTPS API; данные не заменяются локальным seed. Cookie/Authorization не отправляются. Нет входа и приватного кеша на диске. Штатная TLS-проверка, запрет cleartext и redirect. Origin и CSRF сервера не менялись. В APK лишь публичный адрес API.

DTO учитывает snake_case, null вложения, числовой next и строковой after. Ошибка доступа удаляет прежнее содержимое; сетевой отказ пагинации сохраняет страницу и курсор. Новая загрузка отменяет старую и проверяет поколение запроса. Назад отменяет незавершённую загрузку поста.

## Сборка

minSdk 26, compile/target 36; временный applicationId ru.wrcommunity.android.preview. JDK 17 / Gradle 8.14.3 / AGP 8.11.1 / Kotlin 2.2.0 / BOM 2025.06.01. [Матрица AGP](https://developer.android.com/build/releases/agp-8-11-0-release-notes). Wrapper и checksum закреплены. Это стабильная пилотная основа; предупреждения о более новых версиях не подавляются.

## Критерии и проверки

- assembleDebug и lintDebug; 8 существенных unit-тестов.
- assembleDebugAndroidTest: тестовый APK для эмулятора.
- Инструментальный сценарий: реально доступный клуб/пост, поиск, переходы и назад; 200% текста и screenshots.
- Отдельно: реальный телефон, TalkBack, minSdk 26, поворот/восстановление процесса, сеть и анимации на устройстве.

Локальный Windows AVD пробовался read-only без изменения исходных данных: аппаратные старты зависали, программный запуск не завершился; ограниченный процесс встретил отказ создания служебного lock. Не отключать TLS или серверные права для обхода этой проблемы. Отдельный Linux/KVM CI используется для проверки установки.

## Что дальше

A02: вход/регистрация/восстановление, защищённый cookie-сеанс, logout/отзыв/смена аккаунта и приватный кеш. Полный app-сценарий, push, offline-очередь, релизная подпись и магазин не входят в A01.

Проверка CI выявила нехватку диска для стандартного userdata Pixel 7 (7.37 GB при доступных 7.25 GB). Размер тестового userdata ограничен 4 GiB, RAM — 2 GiB; это настройки временного эмулятора, не изменение пользовательского телефона или данных сервера.

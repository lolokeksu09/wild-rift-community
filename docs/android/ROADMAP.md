# Этапы разработки Android

Дата 05.10.2026. Этапы завершаются доказательствами, а не количеством экранов. После каждого этапа обновлять [STATUS.md](STATUS.md) и существенные контракты.

| Этап | Результат | Критерий приёмки | Статус |
|---|---|---|---|
| A00 | Репозиторий, архитектура, дизайн, карта API и задач | Ссылки проверены, история сохранена, runtime не сломан | Документы подготовлены |
| A01 | Настоящий гостевой APK | Каталог → открытый клуб → пост с реального HTTPS API; loading/error/offline; назад; сборка и установка | Реализован, установка в проверке |
| A02 | Аккаунт и безопасный сеанс | Вход/регистрация/восстановление, профиль, пароль/сеансы; перезапуск, отзыв и смена аккаунта без утечки | Не начат |
| A03 | Полный клубный контент | Вступление/заявки, лента, фото, пост, комментарии/реакции/сохранение; повтор без дубля и отказ чужого доступа | Не начат |
| A04 | Переписка | Согласие на знакомство, лимиты, личный/клубный чат, страницы; блокировка/отзыв/потеря ответа | Не начат |

| A06 | Управление и модерация | Роли, участники/заявки, жалобы/апелляции, журнал; владелец/модератор/обычный пользователь | Не начат |
| A07 | Полировка и надёжность | Доступность, движение, длинные списки, память, плохая сеть; измерение на целевых устройствах | Не начат |
| A08 | Тестовый выпуск и обновления | Постоянная подпись, установка обновления, политика данных, восстановление сервера, release checklist | Не начат |

## Как выполнять

Один этап может иметь несколько PR, но каждый PR даёт законченный проверяемый сценарий. Использовать [шаблон](../templates/ANDROID_TASK.md). Зависимости и stable версии выбирать при реализации; не добавлять библиотеки впрок.

На каждом этапе: собрать APK, выполнить lint и существенные тесты; установить и пройти сценарий на устройстве/эмуляторе; проверить сеть и права; записать версии и ограничения. Если установка невозможна, этап остаётся частично проверенным.

Анимации добавляются вместе с первыми экранами по [дизайну](DESIGN_SYSTEM.md), затем измеряются на A07. Доступность не откладывается до A07. Ни push, ни offline-очередь не обещаются до отдельной реализации.

Для A08 нужно решить имя/applicationId, minSdk и распространение, релизную подпись, политику хранения/удаления/экспорта аккаунта. Независимые резервные копии и проверка восстановления — серверная обязанность, которую появление APK не закрывает.

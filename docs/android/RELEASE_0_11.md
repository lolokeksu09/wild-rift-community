# Android 0.11.0-preview

Главная начинает с людей и разговоров: свежие публикации с аватаром автора и названием клуба подняты перед каталогом. Вместо трёх больших объясняющих карточек — компактные кнопки поиска игроков, команд и игровых вечеров. Открытые профили доступны нажатием на аватар с именем; признаки демо-наполнения сохранены.

Шапка и каталог стали компактнее: открытая композиция без крупной градиентной подложки, золотой знак Рифта, Manrope, короткое описание и меньшие обложки клубов. Действия, серверные данные, состояния частичной загрузки и права сохранены. Счётчики онлайна и игровая активность не выдумываются.

VersionCode 11. Сборка, lint, JVM и инструментальная проверка должны быть выполнены для этого исходного commit; результаты предыдущего APK не подтверждают новую версию. Локальная сборка недоступна: Gradle не скачивается из-за ограничения сети, SDK отсутствует. Реальная визуальная приёмка нового экрана на телефоне, TalkBack и API 26 остаётся необходимой.

Prerelease с временной debug-подписью. При несовпадении подписи потребуется переустановка и повторный вход. Push отсутствует. Сервер, main, миграции и VDS Deploy не изменяются.

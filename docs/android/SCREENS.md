# Экраны и навигация Android

Целевая карта. Гостевые каталог, клуб и пост A01 реализованы; вход/регистрация/восстановление и профиль/безопасность A02 добавлены в 0.2.0-preview. Остальные области — будущие задачи.

## Основной путь

Гость открывает каталог без обязательного входа → выбирает открытый клуб → читает публикацию. Закрытый клуб показывает только разрешённое сервером описание; чтение приватного контента требует членства. Вход сохраняет выбранную цель и не выполняет вступление автоматически.

В 0.2.0 работают два раздела: Клубы / Профиль. Профиль гостя предлагает вход. Целевые дополнительные Главная / Сообщения добавляются вместе с реализацией. Люди, объявления, события, сохранённое и уведомления доступны из подходящего раздела; не перегружать нижнюю навигацию.

## Состояния и обратная связь

Каждый экран: первая загрузка, содержимое, пустота, ошибка с повтором, нет сети и нет доступа. Refresh не скрывает уже показанное. Отказ отправки оставляет текст и выбранные файлы; если результат неизвестен, показать это и повторять с тем же поддерживаемым clientId.

401 предлагает повторный вход и очищает приватные данные. 403 не предлагает обход роли. 404 объясняет недоступность без раскрытия закрытого содержимого. 429 сохраняет форму и показывает паузу по фактическому ответу. Отозванное членство закрывает чат, историю и изображение.

## Стек и ссылки

У каждой вкладки свой стек/позиция. Назад: закрывает клавиатуру/модальную поверхность, затем детали, затем основной экран. Поворот не сбрасывает фильтры. Незавершённый ввод требует сохранения draft или явного подтверждения ухода; destructive действия подтверждаются внутри продукта.

На A01 внутренние маршруты clubId/postId. Внешние ссылки нормализовать по allowlist собственного HTTPS host и путей; посторонние адреса открыть системно. App Links требуют домена и assetlinks с релизной подписью, поэтому не считать их готовыми по обработке intent. После входа проверить право на цель заново.

Проработать реальную карту навигации на A01; [дизайн](DESIGN_SYSTEM.md) задаёт переходы. Не обещать все разделы в первом APK: недоступные разделы либо отсутствуют, либо честно объясняют статус.

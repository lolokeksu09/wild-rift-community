# Перенос возможностей сайта в Android

07.10.2026. Цель — все действующие пользовательские функции веб-клиента, а не новые функции сервера. Код выпуска 0.10.0-preview использует существующий HTTPS API и общие аккаунты.

| Возможности сайта | Нативный раздел | Подробности |
|---|---|---|
| Вход/регистрация/восстановление/профиль/сеансы | Профиль | AccountRepository, AccountScreen; расширенные игровые поля и фотографии |
| Главная/сохранённое/личные рекомендации | Главная и меню | [Discovery](DISCOVERY_PORT.md) |
| Каталог/участие/управление клубом | Клубы → единый экран клуба | [Контент](CONTENT_PORT.md) |
| Публикации/редактирование/ответы/реакции/опросы/руководства/черновики | Лента, клуб, публикация | [Контент](CONTENT_PORT.md) |
| Личные знакомства/согласие/переписка/блокировки/приватность | Сообщения; Все разделы | [Переписка](MESSAGING_PORT.md) |
| Клубный чат и история | Клуб → чат | [Переписка](MESSAGING_PORT.md) |
| Игроки/профили/игровые поля/каталог сообщества | Все разделы → Игра вместе | [Discovery](DISCOVERY_PORT.md) |
| LFG/заявки/состав/чат | Команды и объявления | [Discovery](DISCOVERY_PORT.md) |
| События/места/роли/часовые пояса/чат | Игровые вечера | [Discovery](DISCOVERY_PORT.md) |
| Уведомления и отметки прочтения | Значок уведомлений; Все разделы | Пять категорий существующего сервера |
| Жалобы/результаты/апелляции/модерация/удаления | Мои жалобы; очередь для модератора | [Модерация](MODERATION_PORT.md) |
| Правила/фотографии/публичные ссылки | Нативные страницы, picker и sharing | Правила перенесены из фактического веб-текста |

Контроль границ: общая FeatureClient использует тот же CommunityApi/cookie jar; мутация без CSRF не отправляется; ответ прежнего аккаунта отбрасывается. При смене аккаунта очищаются модели, маршруты, приватные данные и неподтверждённые попытки. Решения, удаления и блокировки требуют явного подтверждения. Повтор записи происходит вручную с сохранённым clientId там, где сервер поддерживает идемпотентность.

Не относятся к существующей функциональности сайта: push, офлайн-синхронизация и постоянная APK-подпись. Известные различия: длинные новые списки пока используют прокручиваемую Column; незавершённые формы вне переписки не гарантированно переживают завершение процесса. Уведомление обсуждения теперь загружает страницу нужного ответа и прокручивает к нему. Ручная приёмка всех действий, TalkBack и API 26 не подменяются успехом компиляции. Итог проверок записывается в STATUS только после выполнения.

Оформление 0.9: единая тема Manrope/графит/золото, реальная публичная главная для гостя, резервные обложки и аватары, клубные вкладки, закреплённый composer, зашифрованная очередь с проверкой доступа и общие счётчики уведомлений. Подробности выпуска — [RELEASE_0_9](RELEASE_0_9.md).

Функциональный проход 0.10 и границы доказательств: [SCENARIO_WALKTHROUGH](SCENARIO_WALKTHROUGH.md), описание выпуска — [RELEASE_0_10](RELEASE_0_10.md).

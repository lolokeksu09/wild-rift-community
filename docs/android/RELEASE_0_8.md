# Android 0.8.0-preview

Нативные разделы сообщества на Kotlin/Compose: главная, клубы и участие, публикации/ответы/реакции/сохранение, опросы и руководства, серверные черновики, личная и клубная переписка, поиск игроков, команды и игровые вечера, уведомления, жалобы и модерация. Управление клубом включает заявки, роли, исключения/баны, приглашения, передачу владения, закрепления и журнал. Фотографии выбираются стандартным Android picker; профиль получил роли, чемпионов, время игры, микрофон, видимость Riot ID, аватар и обложку. Публичные ссылки на клубы, посты и профили можно открыть в приложении и отправить другим.

Приложение использует действующий сервер и его проверки Origin/CSRF, членства, блокировок и санкций. Никаких WebView, новых серверных маршрутов, миграций или производственных данных этот выпуск не добавляет. Перенесены действия, которые реально доступны в веб-клиенте; интерфейс не обещает редактировать события/команды, если сервер этого не поддерживает.

Перед публикацией CI собирает APK, выполняет lint, JVM-контрактные тесты и инструментальные проверки на Android 15/API 35. Наличие этих тестов не доказывает ручную приёмку каждого нового сценария. Ручная проверка новых форм, TalkBack, минимального API 26 и производительности больших списков остаётся необходимой. Неотправленные сообщения и формы хранятся в процессе приложения; они переживают поворот через ViewModel, но не гарантированно завершение процесса. Серверные черновики публикаций сохраняются отдельно. Уведомления используют опрос; push отсутствует на сервере.

Это prerelease с временной debug-подписью. Обновление поверх старой сборки не гарантируется. При несовпадении подписи потребуется переустановка и повторный вход; прежде сохрани доступ к аккаунту. Исходный commit и SHA256 публикуются вместе с APK. Предыдущие APK не заменяются.

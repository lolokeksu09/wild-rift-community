# Нативная переписка

Compose-клиент использует существующие серверные API без WebView. Входящие/отправленные/отклонённые запросы, страницы бесед и общие счётчики, создание первого сообщения, согласие получателя, приватность новых запросов, список блокировок и снятие блокировки реализованы отдельным MessagingViewModel.

Личные и клубные комнаты читают историю по 50 сообщений; ранняя история загружается кнопкой, новые страницы догружаются последовательно при опросе. Ручное обновление заново читает весь уже загруженный диапазон от последней страницы до прежней ранней границы и заменяет историю, убирая удалённые сообщения. Опрос работает каждые 2 секунды только для открытой комнаты при STARTED lifecycle. Список получает счётчики каждые 5 секунд с увеличением паузы при ошибках до 60 секунд. Отметка прочтения доступна только личным беседам: API для клубного прочтения отсутствует. Смена blockVersion очищает клубную историю и загружает актуальную страницу; меньшая версия отвергается. Подтверждение отправки не двигает входящий курсор.

Черновики и очередь до 20 неподтверждённых сообщений разделены по комнате и очищаются при смене аккаунта. Успех первого запроса очищает только неизменённый отправленный черновик: новый ввод во время ожидания сохраняется. Повтор происходит только по явному нажатию и сохраняет clientId и исходный текст. Удаление очереди подтверждается с предупреждением, что доставленная запись не удаляется. Отклонение запроса и блокировка требуют подтверждения. Жалобы передают точные серверные виды club/direct через раздел модерации. Ошибки доступа очищают приватный контент.

Ограничения: очередь и черновики находятся в памяти ViewModel, переживают поворот экрана, но не закрытие процесса; сохранение в зашифрованное хранилище ещё не реализовано. Счётчики и комнаты используют HTTP-опрос, push отсутствует на сервере. Реальная установка, TalkBack, крупный текст и сценарии отзыва доступа на устройстве требуют отдельной проверки. Контрактные JVM-тесты покрывают парсинг страниц, общие счётчики, бюджет, маршруты и идентификатор повторной отправки; это не заменяет проверки полного UI/HTTP сценария.

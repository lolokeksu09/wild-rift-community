## Организация работ

Задачи оформляются как Issues с кодами TASK-01–TASK-17, этапом, целью, критериями приёмки и зависимостями. Ссылки на созданные карточки хранятся в BACKLOG.md.

Этапы M0–M4 описаны в ROADMAP.md. GitHub Milestones, отдельная доска Projects и пользовательские метки пока не настроены: соответствующих операций нет в доступном коннекторе. Не считать заголовки этапов созданными milestones.

Предлагаемые статусы доски: Backlog, Ready, In progress, Review, Done. Предлагаемые метки: type:feature, type:bug, type:docs, type:security; priority:p0/p1/p2; area:auth/clubs/feed/chat/lfg/moderation/infra.

После выбора стека добавить CI и защиту основной ветки с учётом возможностей аккаунта. Не требовать несуществующие проверки. Лицензия кода ещё не выбрана.

## Рабочий порядок

Одна задача → рабочая ветка → изменение → проверки → PR. В описании PR указать причину, поведение, фактические проверки и риски. Не публиковать секреты и данные пользователей. Не переписывать общую историю без необходимости.

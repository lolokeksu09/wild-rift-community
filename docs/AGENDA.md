# Мои игры — этап 37

Личный раздел `/games`: игровые события и матчи турниров на одной странице. Доступ через навигацию «Играем вместе». Не требует изменения SQLite: схема остаётся 30.

GET `/api/agenda?type=all|events|tournaments&status=all|upcoming|completed|cancelled&cursor=...` доступен только вошедшему пользователю. Возвращает viewerId, items, nearest, next. Страница — до 50 записей. Курсор связан с аккаунтом и фильтрами; чужой или повреждённый курсор — 422. Неподдерживаемый метод — 405, гость — 401.

Событие включается для организатора либо игрока, занимающего роль в актуальном составе. Выход/исключение удаляет событие из списка участника. Статус: отменено по флагу cancelled; завершено после ends_at; иначе предстоящее, включая уже идущее событие с отдельной отметкой. Завершённые события сохраняются, пока сохраняется роль участника или организатора.

Матч включается для организатора либо подтверждённого участника одной из команд текущего матча. Ожидающее приглашение не даёт участия. Матч завершается по результату, а не по времени: прошедшее время без результата помечается в интерфейсе. Матчи без даты включены в предстоящие с отметкой «Время пока не назначено». Турниры без построенной сетки не создают выдуманных матчей.

Двусторонние блокировки организатора скрывают записи обоих типов; для матчей дополнительно учитываются капитаны обеих команд. Фильтрация выполняется до пагинации. Ответ не раскрывает чужие составы, идентификаторы пользователей или ключи отправки.

Предстоящие записи идут по времени, без даты — в конце; завершённые и отменённые — от более поздних к ранним. Ближайшая игра — самая ранняя будущая запись с назначенной датой в выбранных фильтрах. Карточка содержит тип, роль, локальное время и часовой пояс устройства; для матча — команды, раунд, счёт или состояние готовности. Ссылки: `/events?id=...` и `/tournaments?id=...&round=...&slot=...`.

Данные читаются из текущих таблиц при запросе. Перенос, отмена, результат и изменение участия отражаются после обновления. Автообновление первой страницы — каждые 30 секунд на видимой странице и при возвращении во вкладку; после подгрузки дополнительных страниц остаётся ручное обновление, чтобы не сбрасывать читаемый список. Смена фильтров и ручное обновление начинают пагинацию заново. При изменении расписания между страницами список может изменить порядок; для полной актуализации нажать «Обновить». Ошибка обновления сохраняет уже загруженный список и выбранные фильтры. Смена раздела прекращает обновления и запросы.

Личные приглашения и поиск компании остаются в существующих разделах; расписание не создаёт push-уведомлений или новые календарные записи вне сайта.

## Выгрузка календаря — этап 38

`GET /api/agenda/calendar`: signed cookie-сеанс, `type=all|events|tournaments` (по умолчанию all), необязательный `key=event:<id>|match:<tournament>:<round>:<slot>`. Другие параметры отклоняются 422. Выгрузка использует те же проверки участия и двусторонних блокировок, что расписание; все страницы читаются синхронно с одним временем отсечения. Чужой, отменённый или завершённый объект — 404; недатированный матч или матч с прошедшим временем без результата — 422. Пустой общий календарь — 422. Уже идущие события сохраняются до окончания. Выгрузка всех игр не зависит от выбранного в интерфейсе статуса и включает только предстоящие/идущие игры выбранного типа.

Ответ: `text/calendar; charset=utf-8`, `attachment` с именем `wr-game.ics` или `wr-my-games.ics`, `Cache-Control: no-store`. RFC 5545: CRLF, UTF-8 перенос строк до 75 октетов без разрыва символов, экранирование TEXT, UTC DTSTART/DTEND/DTSTAMP, стабильный UID из ключа и проверенного origin сервера, точная URL-ссылка, DISPLAY-напоминание `-PT30M`. Нет списка аккаунтов, приглашённых и приватных переписок. Длительность матчей неизвестна; DTEND для них не выдаётся. Формат: [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545).

Файл — ручной снимок, не автоматическая подписка. Отмена, перенос и выход после импорта не отзывают локальную копию; её удаляет пользователь. Повторный импорт может создать дубли в зависимости от приложения; стабильный UID не гарантирует его поведение. Показ напоминания зависит от поддержки VALARM и настроек телефона. Реальный импорт на Android владельца не проверен.

UI скачивает файл только после успешного ответа; таймаут 10 секунд, отмена при смене фильтров/страницы, проверка текущего аккаунта. При ошибке кнопка снова доступна. Сохранение файла не меняет участие и не помечает уведомления прочитанными. SQLite остаётся 30.

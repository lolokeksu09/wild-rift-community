# Личные сообщения · 0.5

Вкладка «Сообщения»: беседы, входящие, отправленные и отклонённые запросы; создание запроса по точному логину; настройка получения новых запросов; список личных блокировок.

Первый запрос содержит ровно одно сообщение. Только получатель может принять или отклонить его. До принятия дополнительных сообщений нет. Отклонение окончательно для этой пары аккаунтов: повторный запрос не создаётся. Встречный запрос не считается согласием. Одна пара имеет одну беседу.

Принятые беседы используют серверное хранение SQLite, страницы истории по 50 сообщений, опрос раз в 2 секунды и ту же очередь повторов, что чат клуба. Идентификатор отправки предотвращает дубли. Первоначальный запрос сохраняет идентификатор при повторе в открытой форме; после перезагрузки надо обновить список, чтобы проверить доставку. Он не сохраняется как локальный черновик.

Блокировка здесь относится к личной переписке: закрывает чтение и отправку с обеих сторон, скрывает беседу из списка. Снятие всех блокировок возвращает доступ к принятой беседе. Данные не удаляются. Уже полученные копии отозвать невозможно. Общий чат клуба и скрытие сообщений заблокированного автора в нём — отдельная незавершённая часть SPEC. Открытая беседа очищается при следующем запросе с отказом; список запросов обновляется кнопкой. Изменение настройки запросов не отменяет существующие запросы и беседы.

## API

Все маршруты требуют сеанс. Изменения дополнительно требуют Origin, CSRF и X-Community-Request.

- GET /api/direct — только собственные беседы, первые сообщения запросов.
- POST /api/direct — {handle, clientId, body}; создание запроса или повтор той же отправки.
- POST /api/direct/:id/decision — {decision: accept|reject}; только получатель.
- GET /api/direct/:id/messages — принятая беседа; before либо after.
- POST /api/direct/:id/messages — {clientId, body}; принятая беседа.
- PATCH /api/me/privacy — {dmRequests: boolean}.
- GET /api/blocks — собственные блокировки.
- POST /api/blocks и DELETE /api/blocks — {userId}; установить/снять собственную блокировку.

Чужая беседа возвращает 404, блокировка/непринятый запрос — 403. Разрешения проверяются до чтения и повторной отправки. Личные сообщения не имеют сквозного шифрования; оператор базы может их прочитать.

## Миграция и восстановление

Схема 2→3 добавляет таблицы direct_conversations, direct_messages, blocks, индекс истории и users.dm_requests (по умолчанию запросы включены). Ничего не удаляет. Миграция транзакционная. Перед первым запуском остановить сервер и скопировать весь каталог data, включая SQLite sidecar-файлы, если они остались. Для отката остановить новую версию и восстановить копию с соответствующей старой версией приложения. Старый сервер не открывает схему 3. Не понижать user_version вручную.

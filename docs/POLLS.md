# Опросы в клубах · 0.22

## Сценарий

Во вкладке постов клуба принятый участник раскрывает «Создать опрос»: вопрос 1–100 символов, описание до 4000 (необязательно), 2–6 различных вариантов по 1–100 символов и срок. Интерфейс предлагает 1/6/24/72/168 часов; API допускает любое целое 1–168. Дата окончания хранится UTC и показывается в местном времени. После публикации вопрос, варианты и срок не меняются; можно удалить пост обычными правами автора или модератора клуба. Комментарии, реакции, сохранения, поиск и закрепления используют обычную публикацию.

В карточке — варианты, число голосов/проценты, свой выбор, дата окончания и кнопка обновления. Голос один, изменить его нельзя. Имена/ID голосовавших не выдаются; это не обещание невозможности косвенного угадывания по малому составу. Результаты доступны читателям поста, включая гостей открытого клуба; голосование требует принятого членства. Автоопроса результатов/фонового закрытия нет: сервер проверяет время при каждом запросе. Результаты можно обновить явно; поздний новый голос отклоняется, карточка подгружает актуальное закрытое состояние.

## API и права

POST /api/clubs/:id/polls {title,body,options,durationHours,clientId}. Пост/опрос/варианты/обычные упоминания сохраняются одной транзакцией. Повтор того же автора/клуба/clientId и неизменного содержимого возвращает прежний id, другой payload — 409. Потерянный ответ в UI блокирует изменение полей и позволяет повторить ту же попытку, без второго поста. Эти формы не имеют серверного черновика.

GET /api/posts/:id/poll → {viewerId,poll:{endsAt,closed,options:[{option_id,label,votes}],total,myOption}}. PUT /api/posts/:id/poll/vote {optionId} проверяет пост/блокировки и текущее членство, затем вариант/прежний голос/срок в транзакции. PRIMARY KEY(post_id,user_id) исключает второй голос. Тот же вариант повторяется без увеличения счётчика, иной — 409. Старый подтверждённый вариант можно повторить после закрытия, новый голос — нельзя. При неуверенном ответе интерфейс оставляет для повтора тот же вариант и обновление результатов. При отказе 401/403/404 показанная карточка публикации очищается.

Подсчёт включает только актуальных принятых участников, исключая двусторонне заблокированных зрителем игроков. Поэтому результаты могут различаться по зрителю и изменяться после выхода/бана. Выход/исключение удаляет голос вместе с членством; после повторного вступления участник может голосовать снова, если опрос ещё открыт. Бан сохраняет запись, но скрывает голос в подсчёте. Это осознанные правила текущего выпуска.

## Данные и миграция

SQLite 16→17 добавляет polls, poll_options, poll_votes и индекс. Опции ссылаются на опрос, голос — на вариант и пару клуб/опрос, а также на пару клуб/участник. Удаление поста каскадно удаляет всё голосование. Существующие посты/правки/черновики сохраняются. VDS: холодная копия, пробная миграция, integrity/FK, рабочая миграция под обслуживанием, healthcheck, HTTPS. Возврат холодной копии допустим до открытия трафика; после открытия нужно сохранять новые записи.

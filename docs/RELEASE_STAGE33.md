# Этап 33 — единый турнирный модуль

Один архив объединяет исправление результатов с причиной и историей, технические поражения, снятие команды после старта, безопасное обновление сетки, расписания и готовности, уведомления и «Мои турниры». Включены все прежние этапы и утверждённое мобильное оформление.

Снятие после старта доступно, когда в текущем матче определён соперник; состав сохраняется. Исправление блокируется после результата следующего матча. Смена победителя сбрасывает дату и готовность следующего матча.

SQLite 28: добавление снятия/истории и расширение уведомлений с сохранением ID, прочитанности и всех существующих данных. Установщик делает резервную копию. Старое приложение схемы 27 новую базу не открывает.

Проверки: `npm run verify` прошёл: 142 серверных теста и весь DOM-набор. Проверены права, повторы, исправления/история, защита завершённого следующего матча, технические поражения, снятие, сброс расписания/готовности, личные уведомления, пагинация и миграция 27→28 с сохранением данных. Реальный HTTP UI всего блока и синтаксис установщика прошли. CI этапа 33, телефон и установка на VDS не подтверждены. Docker локально не запускался.

# Архитектура сайта

Браузерный клиент в server/public/ обращается к HTTP API server/app.mjs. Тематические серверные модули выполняют проверки прав и операции SQLite. Docker запускает Node.js 24.19, Caddy обслуживает HTTPS. Версия схемы SQLite — 22; Sharp обрабатывает изображения.

Аккаунты, роли, блокировки, лимиты контактов и модерация проверяются сервером для каждого запроса. Изображения сохраняются в media BLOB; скрытый профиль и приватные файлы не становятся доступны через прямую ссылку.

Авторизация использует cookie-сеанс, CSRF, точный Origin и маркер запроса. Не отключать браузерную защиту и не переносить бизнес-правила в UI.

Сохранять каталоги server/public и tests: на них завязаны Docker и проверки. SQLite заменять только при измеренной потребности и отдельном плане миграции. Для эксплуатации — [SERVER.md](SERVER.md), [DEPLOYMENT.md](DEPLOYMENT.md), [BACKUP.md](BACKUP.md). Решения — [DECISIONS.md](DECISIONS.md).

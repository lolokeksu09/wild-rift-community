Установка из Termux после скачивания в /storage/emulated/0/Download:

```bash
unzip -o /storage/emulated/0/Download/wr-community-design-stage24.zip -d "$HOME/wr-deploy"
bash "$HOME/wr-deploy/wr-community-design-stage24/deploy-from-termux.sh"
```

Эта команда выбирает именно зафиксированный этап 24. Помощник wr-deploy-latest.sh всегда выбирает наибольший номер и после будущих выпусков установит другую версию.

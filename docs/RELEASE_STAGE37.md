# Этап 37 — единое расписание «Мои игры»

Личные события и турнирные матчи на одной странице, ближайшая назначенная игра, фильтры типа и статуса, локальное время и участие, готовность и счёт. Точные переходы к событиям и матчам. Актуализация после переноса, отмены, изменения участия и результата; автообновление видимой первой страницы и ручное обновление истории.

Приватный API с фильтрацией членства и двусторонних блокировок до пагинации. Курсор связан с аккаунтом и фильтрами. Матчи без даты явно отмечены; результат не выдумывается по времени.

SQLite остаётся 30, миграция не требуется. Оформление, изображения, черновики и данные сохранены. Целевые серверные и реальный HTTP DOM проверки прошли; полный verify прошёл: 155 серверных тестов и весь включённый DOM-набор. Проверены доступ, блокировки, классификация, перенос/результат, пагинация и привязка курсора; UI — повтор загрузки после ошибки, ближайшая игра, фильтры и точные ссылки. Браузерный сценарий на 320/390/1440 px добавлен в Actions. Локальный Chromium отсутствует; CI и установка этапа 37 пока не подтверждены. Deploy не запускался.

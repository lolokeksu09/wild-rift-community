# Карта экранов и сценариев

Нижняя навигация: Лента · Клубы · Играть · Чаты · Профиль. Поиск и уведомления доступны из шапки. Desktop использует боковое меню. Маршруты ниже — проектные, не существующие адреса сервиса.

| Экран | Маршрут | Основное действие | Особые состояния |
|---|---|---|---|
| Вход | /sign-in | Войти | неверные данные, ограничение, восстановление |
| Лента | /feed | Читать / написать | пусто, загрузка, ошибка, конец списка |
| Пост | /posts/:id | Ответить | удалён, скрыт, доступ отозван |
| Редактор | /compose | Опубликовать | черновик, ошибка загрузки, повтор |
| Каталог клубов | /clubs | Найти клуб | нет совпадений |
| Клуб | /clubs/:id | Вступить / открыть чат | заявка, отказ, блокировка |
| Настройки клуба | /clubs/:id/settings | Управлять | недостаточно прав |
| Поиск группы | /play | Подать заявку | заполнена, истекла, отменена |
| Создание группы | /play/new | Собрать команду | неверное время, лимит |
| Группа | /play/:id | Управлять заявками | нет мест, автор закрыл |
| Чаты | /chats | Открыть беседу | запросы, нет связи |
| Беседа | /chats/:id | Отправить | ожидает, ошибка, доступ отозван |
| Профиль | /users/:handle | Подписаться | блокировка, удаление |
| Настройки | /settings | Изменить приватность | подтверждение важных действий |
| Поиск | /search | Найти | нет доступа к совпадениям |
| Уведомления | /notifications | Открыть событие | цель удалена/недоступна |
| Жалоба | диалог | Отправить | лимит, уже отправлена |
| Модерация | /moderation | Рассмотреть | нет полномочий |

## Сценарий A: познакомиться и сыграть

Гость → регистрация → каталог → открытый клуб → вступление → общий чат → группа для игры → заявка → принятие → беседа группы.

## Сценарий B: публикация

Лента → редактор → изображение и текст → предпросмотр → публикация → ответ другого игрока → уведомление → ответ в комментариях. При ошибке текст сохраняется. Уход со страницы не теряет черновик без предупреждения.

## Сценарий C: нарушение

Сообщение → пожаловаться → причина → подтверждение получения → очередь модератора → контекст → решение и причина → уведомление → апелляция. Блокировка доступна независимо от результата жалобы.

## Прототип

`prototype.html` — самостоятельный кликабельный эскиз пяти основных вкладок. Все персонажи и записи демонстрационные, не реальные игроки. Кнопки не создают серверные сущности. Эскиз проверяет структуру; визуальный стиль и детали не утверждены. Формы авторизации, админка и весь набор состояний описаны здесь, но не отрисованы в эскизе.

### Версия 0.2

Доработаны пять основных вкладок, настольная боковая и мобильная нижняя навигация. Доступны локальные публикации/комментарии, реакции и сохранённое, открытые клубы и заявки, комнаты вступивших клубов, поиск по клубам/постам, создание группы, отмена заявки, редактирование профиля. Состояние сохраняется в localStorage при наличии доступа; при его отсутствии работа продолжается в памяти. Сброс демо требует подтверждения.

Уведомления показывают собственные локальные заявки и объясняют отсутствие внешних событий. Реальные аккаунты, отправка другим людям, загрузка медиа, права доступа и сервер отсутствуют. Управление клавиатурой диалогами опирается на native dialog; визуальная проверка в Chromium пока не выполнена из-за недоступного бинарного файла.

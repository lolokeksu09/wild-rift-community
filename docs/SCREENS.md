# Экраны сайта

Текущая база оформления — [этап 24](DESIGN_BASELINE_STAGE24.md). Состав и история согласованных изменений — [WEB_REDESIGN_PLAN.md](WEB_REDESIGN_PLAN.md).

| Экран | Основной сценарий |
| --- | --- |
| Главная | Читать публикации, открывать обсуждения и клубы |
| Клубы | Найти клуб, вступить, читать и публиковать по правам |
| Найти | Искать компанию, объявления и опубликованные профили |
| Чаты | Общаться в клубах, группах и личных беседах |
| Профиль | Просматривать профиль, редактировать данные и безопасность |
| События | Создать игровой вечер, вступить и открыть приватный чат |
| Публикация | Читать, реагировать, сохранять, комментировать и цитировать |

На телефоне пять нижних разделов; дополнительные экраны доступны через меню. Гостю доступны публичные данные; запись и приватные области проверяются сервером. Сохранять черновики, фокус и доступность действий при экранной клавиатуре.

Аватары и обложки пользователя сохраняются. «Обсудить» на странице публикации переводит к редактору без потери набранного ответа.

[prototype.html](prototype.html) — ранний автономный эскиз для исторического теста, а не текущий интерфейс сервера.

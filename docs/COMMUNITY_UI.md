# Сообщество 0.13

Визуальное направление: графитовый фон, синие акценты, отдельная главная, постоянная навигация, выразительные карточки и страницы участников. Продуктовые ориентиры: Circle (структура пространств), Mighty Networks (люди и знакомства), Bettermode (иерархия разделов), Discord (индивидуальность профиля). Исходные интерфейсы и изображения не копируются.

## Реализовано

- Главная для гостей и участников, хронологическая лента и догрузка.
- GET /api/feed возвращает только посты доступных клубов, исключает клубы с баном; по заявкам — только для member. Каждая страница повторно проверяет права. Пагинация before, максимум 20 постов за запрос.
- Пять разделов в боковой панели на компьютере и нижней панели на телефоне. Жалобы вынесены в шапку, права не изменены.
- Поиск по загруженным карточкам клубов (API возвращает до 100), тип доступа и реальное количество участников. Все названия и описания экранируются.
- Профиль с декоративной обложкой, инициалами, редактируемыми именем и описанием, списком своих клубов и управлением сеансами.
- Обложка страницы клуба и читаемые карточки публикаций.
- Места в карточке группы отображают реальные members/capacity.
- Состояния загрузки, ошибки и пустого сообщества; никаких демонстрационных пользователей на VDS.

Обложки и инициалы формируются интерфейсом. Загрузка изображений, новые игровые поля, публичный профиль другого игрока, события и поиск по всей базе не входят в этот выпуск. Схема SQLite остаётся 10, миграции нет. Расширение img-src data: используется только для встроенных SVG-иконок CSS; скрипты остаются self.

## Проверки и выпуск

npm run verify: серверная проверка приватности ленты, вступления/отзыва/бана и пагинации, существующие серверные и DOM-сценарии. Браузерный CI проверяет 360/390/768/1440 px и сохраняет скриншоты главной и профиля как community-ui. Публикация через прежний Docker workflow с холодной копией данных и возвратом конфигурации при ошибке.

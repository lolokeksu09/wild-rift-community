# Этап 34 — единый центр уведомлений

Один выпуск объединяет ответы и упоминания, события, поиск компании и турниры. Фильтры типов и непрочитанного, общий счётчик, «Прочитать всё», история и повтор загрузки при потере связи. Точные переходы к событию, группе и карточке матча.

Приглашения требуют принятия/отказа: отметка прочитанного не изменяет участие. «Прочитать всё» действует только до снимка списка и сохраняет более новые сообщения. Применяются права закрытых клубов, блокировки и актуальность уведомлений.

SQLite остаётся 28; миграция не нужна. Составы, результаты, изображения, черновики и утверждённое оформление сохраняются. Архив включает весь проект, включая этап 33.

Проверки: `npm run verify` прошёл: 144 серверных теста и весь DOM-набор. Проверены общая пагинация, непрочитанное, доступ/блокировки, защита CSRF, снимок «Прочитать всё», сохранение новых уведомлений и приглашений. Реальный HTTP UI фильтров, прочитанности, точных переходов и повтора загрузки после ошибки прошёл. CI этапа 33 успешен. CI, телефон и установка на VDS не подтверждены. Docker локально не запускался.

## Локально

```text
npm ci
npm run verify
npm start
```

Конфигурация Docker — [deploy/compose.yaml](../deploy/compose.yaml), обработка — [server/start.mjs](../server/start.mjs). Node не загружает произвольный .env автоматически: передать переменные процесса либо воспользоваться предусмотренной Docker-конфигурацией. Перед запуском проверить значения и путь базы; не подставлять рабочую базу в тесты.

Локальное приложение слушает loopback по умолчанию. production требует проверенный PUBLIC_ORIGIN HTTPS. Точные переменные и значения читать в start.mjs и deploy/compose.yaml; секреты не копировать в документы.

## Исторический срез 0.3/0.4 и дополнения аудита

Старые ограничения ниже относятся к первому локальному этапу. Для текущего сервера действуют схема 22 и [CHANGELOG.md](CHANGELOG.md).

Адрес по умолчанию: http://127.0.0.1:3000. Использовать именно 127.0.0.1, не localhost: сервер проверяет Host. При занятом порте задать PORT от 1024 до 65535. COMMUNITY_DB задаёт путь SQLite; по умолчанию `data/community.sqlite` относительно рабочей директории. Это локальная конфигурация, не команда для Amvera или телефона.

Для проверки двух пользователей открыть обычное и приватное окно на одном компьютере. Создать разные аккаунты с отдельными тестовыми паролями. Владелец создаёт клуб; второй аккаунт вступает или подаёт заявку. После принятия он пишет пост, а владелец отвечает.

База создаётся автоматически. Остановка процесса и повторный запуск сохраняют записи и действующие сеансы. Для копии базы остановить сервер и скопировать каталог data целиком. Не удалять базу для обычного обновления кода. Схема имеет user_version=2. Обновление 1→2 добавляет сообщения; неизвестная более новая версия отклоняется. До первого запуска поверх версии 0.3 остановить сервер и скопировать каталог data. Откат старым кодом требует восстановления копии: версия 0.3 не открывает схему 2. Подробнее в CHAT.md.

## Границы безопасности

- Привязка только к 127.0.0.1; production-запуск запрещён.
- Cookie HttpOnly/SameSite=Strict; Secure не включён, потому что локальный HTTP. Это нельзя переносить в публичный запуск без TLS и настройки cookie.
- Изменяющие запросы проверяют точный Origin, служебный заголовок и CSRF-токен сеанса (кроме первичного входа/регистрации).
- Пароль: scrypt N=32768,r=8,p=1, случайная соль 16 байт. Токен сеанса: 32 случайных байта; в БД хранится SHA-256 токена, а не cookie.
- Сеанс действует 7 дней; есть отзыв всех сеансов. Просмотр списка отдельных сеансов ещё не реализован.
- Ограничение авторизации: 20 попыток/минуту на IP, до четырёх вычислений хеша одновременно; записи: 120/минуту на пользователя; поиск (`/api/posts/search`, `/api/guides`, а также `/api/clubs`, `/api/community-members`, `/api/players` с `q`): 120/минуту на аккаунт, для гостя — на адрес клиента; `/sitemap.xml`: 10/минуту на адрес. Лимиты в памяти одного процесса.
- Права проверяются на чтение/запись клубных постов и комментариев, включая прямые адреса.
- Статические ресурсы выдаются строго по четырём маршрутам; база, исходники и документы HTTP-сервером не публикуются.
- Лимит JSON 16 КиБ. Пользовательский текст экранируется клиентом. Нет вставки HTML пользователя.

## API среза

Все изменяющие запросы: application/json, Origin текущего адреса, X-Community-Request: 1. Авторизованные изменения дополнительно требуют X-CSRF-Token из GET /api/me. Примеры полей — имена схемы, не секреты.

| Метод | Путь | Данные / результат |
|---|---|---|
| POST | /api/register | handle, name, password → user, csrf, cookie |
| POST | /api/login | handle, password → user, csrf, cookie |
| GET | /api/me | свой профиль и csrf либо user=null |
| PATCH | /api/me | name, bio; только собственный профиль |
| POST | /api/logout, /api/logout-all | пустой объект; отзыв сеансов |
| GET/POST | /api/clubs | список / name, description, access=open или request |
| POST | /api/clubs/:id/join, /leave | вступить / выйти или отменить заявку |
| GET | /api/clubs/:id/members | список для владельца |
| POST | /api/clubs/:id/decision | userId, decision=approve или reject |
| POST | /api/clubs/:id/ban | userId; запрет вступления и доступа |
| GET | /api/clubs/:id/posts?before=:cursor | 20 записей и next |
| POST | /api/clubs/:id/posts | title, body; только член клуба |
| GET/DELETE | /api/posts/:id | чтение / удаление автором |
| GET/POST | /api/posts/:id/comments | последние 100 / body |

Коды: 400 неверный JSON; 401 нет входа; 403 запрет; 404 отсутствует; 409 конфликт; 413 размер; 415 формат; 422 поля; 429 лимит. Каталог ограничен 100 клубами, комментарии — последними 100; полный поиск/пагинация этих списков ещё впереди.

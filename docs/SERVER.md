# Сервер: текущая основа Android

Проверено по исходникам 05.10.2026: package.json 0.31.0, Node.js >=24.19.0 <25, Sharp 0.35.5, встроенный SQLite. Историческое описание локальной 0.4 сохранено в [архиве](history/2026-10-05-SERVER.md).

## Локально

```text
npm ci
npm run verify
npm start
```

Конфигурация Docker — [deploy/compose.yaml](../deploy/compose.yaml), обработка — [server/start.mjs](../server/start.mjs). Node не загружает произвольный .env автоматически: передать переменные процесса либо воспользоваться предусмотренной Docker-конфигурацией. Перед запуском проверить значения и путь базы; не подставлять рабочую базу в тесты.

Локальное приложение слушает loopback по умолчанию. production требует проверенный PUBLIC_ORIGIN HTTPS. Точные переменные и значения читать в start.mjs и deploy/compose.yaml; секреты не копировать в документы.

## Данные и контракт

Текущая схема — 20. Схема и миграции определяются server/database.mjs; не править номер схемы ради клиента. База содержит аккаунты, членства, контент, сообщения, сеансы и BLOB изображений. Приватные файлы выдаются после проверки доступа.

Начальные маршруты Android — [API_CONTRACT.md](android/API_CONTRACT.md). Cookie/CSRF/Origin контракт ещё не проверен из APK. Сайт и приложение должны использовать одни серверные правила.

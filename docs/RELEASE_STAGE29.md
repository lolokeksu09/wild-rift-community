# Этап 29 — исправление установочной проверки

Исправлена ошибка `Demo seed failed`: генератор создаёт 24 демо-бота, а вместе с исходным тестовым аккаунтом получается 25 аккаунтов. В этапе 28 ожидание числа новых ботов было ошибочно изменено на 25 при обновлении номера схемы.

Добавлена регрессия: выполняется фактическое JS-выражение из deploy/smoke-image.sh на холодной копии схемы 18. Проверяются миграция в 25, два запуска seed без дубликатов, передача клубов реальному аккаунту, обработка изображения и неизменность исходной базы. Локальное выполнение выражения не проверяет ограничения Docker.

npm run verify прошёл: 126 серверных тестов и DOM-проверки. Функции этапа 28 и схема 25 сохранены. GitHub Actions, визуальная проверка на настоящем телефоне и установка выпуска на VDS отдельно не подтверждены.

Ошибка smoke-проверки в штатном установщике возникает до переключения работающего сайта. Скачай новый ZIP в Download и повтори обычную команду Termux. Архив имеет новый номер, поэтому помощник выберет его вместо этапа 28.

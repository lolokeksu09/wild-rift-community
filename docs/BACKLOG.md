# Задачи первого выпуска

> Документ ранней организации проекта. Текущие этапы Android — [ROADMAP](android/ROADMAP.md), состояние — [STATUS](android/STATUS.md). Статусы старых Issues не означают готовность APK.

Созданы GitHub Issues #1–#17. Ниже — критерии и зависимости; текущее состояние смотреть в карточках.

## TASK-01: Зафиксировать решения старта

[Открыть #1](https://github.com/lolokeksu09/wild-rift-community/issues/1)

Этап: M0. Приоритет: P1.

Цель: Выбрать имя, видимость репозитория, формат первого клиента и границы пилота.

Приёмка: DECISIONS содержит принятое решение и открытые вопросы; рекомендации не обозначены как утверждённые.

Зависимости: —.

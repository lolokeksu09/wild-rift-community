# Этап 39 — настройки уведомлений

Полный выпуск включает этапы 1–38 и утверждённый дизайн.

- Пять категорий: ответы и упоминания, игровые события, поиск компании, турниры, публикации клубов. Настройки сохраняются в аккаунте; по умолчанию все категории включены, поведение старых аккаунтов сохранено.
- Выключенная категория не увеличивает общий счётчик, а события и поиск компании также не увеличивают свои навигационные счётчики. Чаты и решения по жалобам сохраняют собственное поведение.
- В «Все типы» выключенные категории скрыты; история остаётся доступной через отдельный фильтр или «Показать отключённые категории». Ожидающие турнирные приглашения остаются видны до решения, даже при выключенных оповещениях о турнирах.
- Отключение не удаляет историю, не меняет прочитанность и не принимает приглашения. Новые записи продолжают сохраняться по существующим правилам. «Прочитать всё» вручную отмечает и выключенные категории до границы снимка, сохраняя более новые уведомления.
- Настройки клубных публикаций здесь не изменяют подписки на отдельные клубы. При включённой категории поступают только публикации клубов, на которые участник подписался.
- После потери ответа повтор сохраняет выбранное значение; настройки чужого аккаунта не отображаются. Старую страницу уведомлений следует обновить после установки.

Настройки касаются уведомлений внутри сайта. Push, email и напоминания календаря телефона не изменяются.

SQLite **31**: добавляется таблица личных настроек с удалением при удалении аккаунта. Существующие данные сохраняются, никаких категорий автоматически не выключается. Установщик предварительно проверяет миграцию холодной копии и сохраняет резервную копию. Приложение схемы 30 не открывает базу 31; после установки не откатывай базу автоматически, теряя новые данные. Workflow VDS Deploy не изменён; боевой deploy не выполнен.

Проверки: реальный HTTP/SQLite для настроек, доступа, CSRF, повторов, счётчика, сохранности истории, приглашений, курсоров и миграции; DOM для потери ответа и повтора с выбранным значением. Итог verify/CI — в [PROJECT_STATE.md](../PROJECT_STATE.md).

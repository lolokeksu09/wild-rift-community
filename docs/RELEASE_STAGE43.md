# Этап 43 — моя команда и приглашение игроков

Карточка своей команды появляется перед общим списком: название, число подтвердивших из пяти, статус и строки участников. Капитан ищет игроков по имени или логину, выбирает результат с аватаром и отдельно отправляет приглашение. Точный логин по-прежнему можно ввести вручную. Выбор не отправляет приглашение автоматически и не резервирует место.

Поиск доступен капитану до старта. Скрытые профили, демо-аккаунты, блокировки, действующие ограничения и занятые участники исключаются. Сервер повторно проверяет доступность и лимит при отправке. Правила и история раскрываются отдельно; снятие заявки и выход вынесены в отдельный блок с подтверждением. Участие сохраняет личное согласие.

Схема SQLite остаётся 33; миграция не требуется. Установщик сохраняет резервную копию перед переключением. Дизайн этапа 24, изображения, игровые правила и прежние сообщения сохранены.

Проверки: приватность поиска, лимит, изменение видимости после поиска; интерфейс выбора, ошибки сети, повтор приглашения после потери ответа, запоздавшие ответы, Escape и уничтожение экрана. Итоговый verify, Docker и браузерный CI фиксируются в PROJECT_STATE.md после завершения. Мобильный браузер проверяется на 320/390/1440 px; реальная Android-клавиатура остаётся отдельной проверкой. Deploy выполняется по поручению владельца после успешного CI.

# Проверки и готовность

## Сквозные сценарии

A: два аккаунта регистрируются → вступают в клуб → обмениваются постом/комментарием → создают группу → заявка → принятие → чат. Данные остаются после перезагрузки и входа на другом устройстве.
B: третий аккаунт без членства пытается прочитать закрытый пост, медиа, чат, поиск и уведомление — доступ не предоставлен.
C: участника исключают во время открытого чата — дальнейшие чтение и отправка прекращаются; связанные выдачи учитывают отзыв.
D: два одновременных принятия на одно место — принято только одно; состояние группы согласовано.
E: сеть пропадает при отправке — повтор возвращает то же сообщение, не создаёт дубль.
F: жалоба → рассмотрение → ограничение с причиной → уведомление → апелляция; модератор клуба не получает доступ к личным сообщениям.
G: сброс доступа, отзыв сеанса и блокировка работают на сервере.
H: восстановление резервной копии на отдельном стенде; проверка связности сообщений и членства.

## Интерфейс

Основные экраны на ширинах 360, 390, 768, 1440 px; клавиатура, фокус, масштабирование текста, экранная клавиатура телефона. Пустое состояние, медленная загрузка, ошибка, повтор, удалённая цель ссылки. Демонстрационные данные отделены от реальных.

## Готовность задачи

Критерии выполнены; права проверены; существенные проверки записаны; миграции описаны; документы актуальны; секретов нет. Не писать тесты, которые лишь повторяют реализацию и не проверяют риск.

## Готовность публичного запуска

Назначены модераторы и поддержка, определены правила данных и материалов, проверены восстановление и основные ограничения доступа, отсутствуют известные критические дефекты. Нагрузочные цели из ТЗ измерены, результаты и ограничения записаны. Серверные и веб-проверки дополняются приёмкой сайта в мобильном и настольном браузере.



Локальные Markdown-ссылки проверяются npm run check:docs; внешние URL и якоря — отдельно.

## 8 октября 2026 · восстановление браузерных проверок этапа 24

Причина первого сбоя Verify: размеры намеренно скрытых мобильных кнопок проверялись как у видимых. Теперь проверяются видимые кнопки, их число (пять на телефоне, семь на широком экране), границы и пересечения. Сценарии обновлены для текущих меню, заголовков, карточек, двух кнопок редактирования профиля и свёрнутых блоков. «Обсудить» проверяется на сохранение текста, адресата ответа и перевод фокуса к редактору; новые ответы другого участника читаются после обновления страницы.

Два воспроизведённых дефекта CSS устранены переносами: длинное название клуба на странице публикации при 320 px и текст разделов профиля при увеличении шрифта вдвое. Цвета, типографика, композиция и мобильный масштаб не менялись.

Локально прошли `npm run verify` и 22 браузерных сценария в Firefox. Наполненный интерфейс: 80 проверок на 320/360/390/430/1440 px, без ошибок layout и JavaScript; мобильный ввод: 24 состояния чатов, шесть форм и шесть страниц с удвоенными CSS-шрифтами. Отдельный сценарий приветствия прошёл проверки layout, но его CDP-проверка жеста требует Chromium и локально в Firefox не выполнялась. Полный `npm run test:browser --prefix tests` выполняется в Chromium в GitHub Actions. Это не проверка настоящей клавиатуры Android и не подтверждение боевой выкладки этих исправлений.

В сценарии наполненного сообщества локальные изображения загружаются перед декодированием независимо от прокрутки. Ожидание шрифтов и изображений ограничено десятью секундами; сломанный ресурс вызывает ошибку вместо бесконечного ожидания. Это настройка тестовой страницы, загрузка изображений на сайте не изменена.

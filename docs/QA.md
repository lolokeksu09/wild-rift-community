# Проверки и готовность

## Сквозные сценарии

A: два аккаунта регистрируются → вступают в клуб → обмениваются постом/комментарием → создают группу → заявка → принятие → чат. Данные остаются после перезагрузки и входа на другом устройстве.
B: третий аккаунт без членства пытается прочитать закрытый пост, медиа, чат, поиск и уведомление — доступ не предоставлен.
C: участника исключают во время открытого чата — дальнейшие чтение и отправка прекращаются; связанные выдачи учитывают отзыв.
D: два одновременных принятия на одно место — принято только одно; состояние группы согласовано.
E: сеть пропадает при отправке — повтор возвращает то же сообщение, не создаёт дубль.
F: жалоба → рассмотрение → ограничение с причиной → уведомление → апелляция; модератор клуба не получает доступ к личным сообщениям.
G: сброс доступа, отзыв сеанса и блокировка работают на сервере.
H: восстановление резервной копии на отдельном стенде; проверка связности сообщений и членства.

## Интерфейс

Основные экраны на ширинах 360, 390, 768, 1440 px; клавиатура, фокус, масштабирование текста, экранная клавиатура телефона. Пустое состояние, медленная загрузка, ошибка, повтор, удалённая цель ссылки. Демонстрационные данные отделены от реальных.

## Готовность задачи

Критерии выполнены; права проверены; существенные проверки записаны; миграции описаны; документы актуальны; секретов нет. Не писать тесты, которые лишь повторяют реализацию и не проверяют риск.

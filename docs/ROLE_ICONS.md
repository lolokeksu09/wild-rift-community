# Позиции Wild Rift на сайте

8 октября 2026: названия и изображения позиций взяты из официальной статьи Riot «/dev: подбор по ролям»: https://wildrift.leagueoflegends.com/ru-ru/news/dev/dev-picking-your-position/.

| Неизменный ключ API | Подпись интерфейса | Значок |
|---|---|---|
| baron | Одиночная линия | Топор |
| jungle | Лес | Классический знак леса |
| mid | Средняя линия | Три элемента с крупным центральным |
| dragon | Парная линия | Два элемента |
| support | Поддержка | Классический знак поддержки |

«Линия Барона» и «линия дракона» описывают расположение на карте; названия позиций в указанной статье — «Одиночная линия» и «Парная линия». Ключи API не переименованы: существующие профили, заявки и слоты событий сохраняются. SQLite 22 без миграции.

`server/public/role-icons.jpg` — неизменённая полоса пяти изображений 1000×234 из статьи Riot, служащая источником форм пяти позиций. `role-icons-mask.svg` оборачивает исходное изображение фильтром, который преобразует яркость в прозрачность: фон и тусклое свечение исчезают. CSS-маска окрашивается переменными палитры сайта: обычное состояние — приглушённое, выбранная роль и профиль — акцентные. Формы не перерисованы; исходный JPEG сохранён. Это оригинальные изображения, не рисунки ИИ и не иконки League of Legends для ПК. Нативные select сохраняют текстовые подписи; значки показаны в профилях, карточках, выборе основных ролей и составе события. Изображения декоративные, рядом всегда есть читаемое название.
